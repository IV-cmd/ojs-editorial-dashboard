# OJS fixtures

These clearly synthetic fixtures model OJS 3.6 submission summaries and detail objects from the `pkp-lib/ojs` source schemas. They are not live OJS data and have not been validated against a live OJS instance.

The summary list intentionally omits `reviewAssignments`; each per-submission detail fixture includes `reviewRounds` and `reviewAssignments`, matching the distinct OJS endpoint shapes.
